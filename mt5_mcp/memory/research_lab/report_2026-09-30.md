## Production findings (bonus — discovered during harness build)

- **B1 (crash bug):** `multi_strategy.py` calls `rsi(frame, 14)` with a **DataFrame**;
  `indicators.rsi` does `delta.clip(lower=0.0)` → `TypeError: Invalid comparison
  between dtype=timedelta64[ns] and float` (reproduced). `mean_reversion_strategy`,
  `ema_crossover_strategy`, `btc_trend_following_strategy` would all throw if called;
  they're currently rescued only by `evaluate_all_strategies`' try/except.
- **B2 (dead code):** `momentum_breakout_strategy` compares `current_close >
  window.max()` where the window **includes the current bar** → mathematically
  impossible → can never signal as written.
- **B3 (unreachable gate):** `mean_reversion_strategy` validity gate needs
  `trade_score ≥ 60`; with its own formula that requires RSI ≤ 18.3 → 0 trades in
  8 months (harness confirms).
- **B4 (doc drift):** `evaluate_all_strategies`/`pick_best_strategy` have **zero
  call sites in production** — AGENTS.md "strategy routing" describes unwired code;
  live analysis plans come only from `strategy.evaluate_strategy` (trend_zone).
